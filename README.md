# OPT'IMMO - Installeurs

Ce dépôt public héberge uniquement les installeurs d'OPT'IMMO (`OPTIMMO-Setup-x.y.z.exe`) et leur empreinte SHA-256 (`.sha256`).

**Aucun code source n'est présent dans ce dépôt.**

OPT'IMMO ne fonctionne qu'avec un fichier de licence fourni par Beryl Consulting. Les mises à jour se font depuis l'application : **Administration › Mises à jour**.
